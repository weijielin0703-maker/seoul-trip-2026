📶 韓國 eSIM（威訊 WaySim）

主卡 eSIM QR Code — 長按圖片可加入 eSIM（iOS 17.4 以上）或用另一台手機掃描。一個 QR 只能綁定一台手機，綁定成功後不要刪除 eSIM，也不要把這個頁面分享給別人。

  • 主卡：韓國 5G 高速吃到飽，5天；另有一張 1GB 備援 eSIM，僅限主卡連線異常等緊急狀況時用，不要當一般上網，恢復後聯繫 LINE 客服。
  • 出國當日、網路良好時先完成綁定步驟 1–7：設定 → 行動服務 → 加入 eSIM → 使用行動條碼 → 掃描行動條碼 → 掃描 QR Code 或手動輸入 → 選「只限數據」→ 確認綁定完成；綁定後、未抵達前把 eSIM 保持「關閉」。
  • 抵達後再做步驟 8–10 切換：設定 → 行動服務 → 點入已綁定的 eSIM 並開啟 → 回上一頁再點 eSIM，把「數據漫遊」打開 → 回到行動服務 → 行動數據 → 選 eSIM 方案；「允許行動數據切換」請勿開啟。
  • 注意：QR Code 發送後 30 日內要用，每組 QR 只能綁定一台手機，綁定成功後不要自行刪除 eSIM；開通當天 23:59 為第一天（台灣時間計）；抵達前手機顯示「啟用中」或「無法啟用」通知屬正常，點「好」並把 eSIM 關閉就好。
  • 在韓國有問題：找威訊 LINE 官方帳號 @waysim。
