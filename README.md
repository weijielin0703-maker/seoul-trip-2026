# 首爾 5天4夜 — 旅遊 APP

老婆的韓國首爾旅遊網頁 APP，手機版、單一靜態檔案，不用安裝。黑紫色庫洛米風格。

- 日期：2026/11/14（六）– 11/19（四）凌晨抵台，5天4夜；首爾停留 11/14–11/18
- 住宿：K'STAY Sinchon（新村），5F, 12 Yonsei-ro 4-gil, Seodaemun-gu, Seoul 03779；入住 2026/11/14 → 退房 2026/11/18，共 4 晚；Double Room，1 位成人；含免費 Wi-Fi、咖啡／茶、飲用水；最近地鐵 2號線 新村站約 300 公尺、步行約 4 分鐘；不可退款、No-Show 收 100%、入住須出示與住客姓名相符含地址及照片的證件
- 去程：酷航 Scoot Plus TR872，桃園 T1 11/14 18:15 → 仁川 T1 11/14 21:45，飛行 2小時30分
- 回程：酷航 Scoot Plus TR873，仁川 T1 11/18 23:00 → 桃園 T1 11/19 00:40，飛行 2小時40分
- eSIM：須知分頁有威訊 WaySim 韓國 5G 吃到飽 5 天的一般安裝步驟（出國當日綁定 1–7 步、抵達後 8–10 步切換）；主卡 QR Code 已暫時移除（公開版不含 QR），啟用時用原圖掃描；另有 1GB 備援 eSIM 僅限緊急使用；有問題找 LINE @waysim。

分頁：須知 / 地鐵 / 行程 / 購物（飲料分頁已移除）。行程分頁只有自己新增的網美推薦／小紅書景點（內容＋連結）；Day1～Day5 是獨立的行程表，用導覽列下方的 Day 按鈕進去看（點 Day 切到獨立畫面，點分頁或「← 回到分頁」回來），每天有自己的新增表單。勾選與自行新增的項目存在手機瀏覽器（localStorage）。

- 地鐵簡易規劃：地鐵分頁可選起點／目的地查路線（Dijkstra，換乘加權、機場鐵道每站算 3），顯示路線、方向、站數與估算時間；含 1、2、3、4、5 號線、機場鐵道與水仁·盆唐線部分區間，7、9 號線未收錄；另有 Naver Map 按鈕（開目的地車站搜尋，點 길찾기查完整路線）。
- 導覽列下方有 Day1～Day5 快捷按鈕（獨立於分頁之外，點了切到該天的行程表畫面）；行程分頁的網美推薦存在 localStorage（key 為 `seoul2026:custom:recs`），每天的行程存在 `seoul2026:custom:D1`…`D5`，購物存在 `seoul2026:custom:shopping`，皆附 ✕ 刪除，新增時可附連結（小紅書／IG），會顯示為 🔗 連結；「📋 複製我新增的項目」可把新增項目複製成純文字（連結一併附上），貼給 Muse 寫進 APP（新增項目只存在自己手機，須經此匯出才會出現在老婆手機上）。
- 圖片：標題下方有 LIN 提供的庫洛米跟巴庫橫幅（image-7，垂直裁切 28%～72%、寬 480px JPEG），其下三張小圖拼貼（image-8 緊裁人物、image-9 拼貼、image-10 星空），四個分頁按鈕上有 22px 圓形庫洛米小圖；整體背景維持黑暗系 #17101f。

航班、住宿、eSIM 以 LIN 提供的 PDF 為準。影片只是別人的範例，範例內容已全部從 APP 移除，不再保留。
