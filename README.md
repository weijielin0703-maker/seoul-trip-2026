# 沖繩 3天2夜 — 旅遊 APP

LIN 的沖繩旅遊網頁 APP，手機版、單一靜態檔案，不用安裝。日落到夜霓虹風格（黃昏海洋、夕陽、美國村夜色）。

- 日期：2026/11/25（三）– 11/27（五），3天2夜；那霸・美國村・北谷
- 去程：虎航 IT230，桃園 T1 11/25 06:35 → 那霸 08:55
- 回程：虎航 IT233，那霸 11/27 21:30 → 桃園 T1 22:05
- 租車：Relax 那霸空港店，11/25 10:00 取車，車型 Raize；11/27 18:00 還車，還車前 17:00 加滿油
- 住宿：Airbnb，牧志1-8-2（國際通附近）；入住 11/25 15:00（14:00 後會收到大門密碼）；退房 11/27 10:00 前

分頁：須知 / 行程 / 購物。行程分頁只有自己新增的想去的地方；Day1～Day3 是獨立的行程表，用導覽列下方的 Day 按鈕進去看（點 Day 切到獨立畫面，點分頁或「← 回到分頁」回來），每天有固定行程（可打勾）與自己的新增表單。勾選與自行新增的項目存在手機瀏覽器（localStorage）。

- Day1 11/25（三）：03:40 新店出發、04:35 前到桃園 T1、06:35 IT230 起飛、08:55 抵達那霸、10:00 取車、中午前後 AEON 小祿／糸滿魚市場／瀨長島、15:00 入住、16:00 HUU'S COFFEE、逛國際通和 Bic Camera、18:30 琉球の牛 國際通店、22:00 Churasun 6
- Day2 11/26（四）：09:30 出發、10:00 PARCO City、12:30 美國村午餐、13:30 AEON 北谷、14:30 The Calif Kitchen、17:30 Sunset Beach 看夕陽、18:15 燒肉王北谷店（到店要先報到）、20:15 再逛美國村回那霸；MaxValu 牧志店 24 小時營業
- Day3 11/27（五）：10:00 前退房、車停國際通附近買伴手禮、11:30 焼肉もとぶ牧場 國際通店（Hotel Roco Inn Naha 2F，無停車場；遲到 10 分鐘以上可能被取消）、下午自由活動、17:00 加滿油、18:00 還車、21:30 IT233 起飛、22:05 抵達桃園

- 導覽列下方有 Day1～Day3 快捷按鈕（獨立於分頁之外，點了切到該天的行程表畫面）；行程分頁的想去的地方存在 localStorage（key 為 `okinawa2026:custom:recs`），每天的行程存在 `okinawa2026:custom:D1`…`D3`，購物存在 `okinawa2026:custom:shopping`，固定行程的打勾狀態存在 `okinawa2026:checked:D1`…`D3`，皆附 ✕ 刪除，新增時可附連結，會顯示為 🔗 連結；新增項目只存在自己手機的瀏覽器裡，不會同步到另一支手機。

## 重要：訂位代號不放公開版

航班 PNR、座位、租車訂單號、餐廳訂位代號（TableCheck、EPARK）、KKday 訂單號等憑證不得放入 APP（repo 是公開的，任何人都能看到），只放航班時間、店名與行程內容。

## 發布

repo 為公開（`weijielin0703-maker/seoul-trip-2026`，repo 名稱仍是舊的首爾名字，內容已改為沖繩），`index.html` 和 `README.md` 在 `main` 分支根目錄。GitHub Pages 網址：https://weijielin0703-maker.github.io/seoul-trip-2026/

本機預覽：`python3 -m http.server` 後打開 `http://localhost:8000/`。
